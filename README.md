# 星屿物语 · StarIsle

一款**星露谷物语式**的网页农场生活游戏：种田、钓鱼、和岛上的 NPC 交朋友、接委托、制造物品，在昼夜交替与四季流转的小岛上慢慢生活。

纯网页运行，打开就能玩，电脑和手机浏览器都支持（手机有虚拟摇杆和触屏按键）。

> 本仓库是游戏的**构建产物**（打包好的静态文件），用于部署和试玩。

## 在线试玩

- Cloudflare Pages：https://starisle-6kb.pages.dev/

## 游戏内容

- **农场经营**：耕地、播种、浇水、收获，作物随季节生长
- **钓鱼系统**：对着水面抛竿，浮标咬钩后遛鱼，不同水域有不同的鱼
- **NPC 社交**：十几位岛民各有性格和立绘，聊天提升好感度，「查看任务」可接取/提交委托
- **制造系统**：收集材料制作工具和物品（300+ 种物品，每种都有专属像素图标）
- **动态世界**：昼夜循环、日出日落的天空与光照变化、银河星野、天气
- **HD-2D 像素渲染**：低分辨率渲染 + 泛光/景深/色调分级，八方旅人式的像素质感

## 本地运行

构建产物是纯静态文件，但不能直接双击 `index.html`（浏览器 `file://` 协议会拦截模块加载）。用任意静态服务器即可：

```bash
# 任选其一，在本仓库根目录运行
npx serve .
# 或
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080`（或命令行提示的端口）。

## 部署到其他地方

把整个文件夹原样上传到任何静态托管即可：Cloudflare Pages、GitHub Pages、Vercel、Netlify、Gitee Pages 等都支持，**不需要构建步骤、不需要后端**。

## 想一起完善游戏？

非常欢迎！你可以：

- **提 Bug / 提建议**：点上方 `Issues → New issue`，描述你遇到的问题或想加的内容（在哪、怎么复现、期望效果，有截图最好）
- **参与讨论**：平衡性、新玩法、新 NPC、新作物鱼类……任何想法都可以开 Issue 聊
- **参与开发**：游戏使用 **Vite + three.js** 开发。本仓库是打包产物（压缩后的代码不方便直接修改），想改代码请在 Issue 里留言联系作者获取源码工程

提 Issue 不用写得很正式，说清楚就行，作者会回复的。
