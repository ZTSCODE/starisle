# 星屿物语（StarIsle）

一款可以直接在浏览器中游玩的 3D 像素风农场生活游戏，也是一个欢迎大家共同参与制作和完善的开源项目。

## 在线游玩

**[打开星屿物语，直接开始游戏](https://ztscode.github.io/starisle/)**

不需要下载安装，也不需要配置开发环境。使用电脑或手机浏览器打开网页即可游玩，存档会保存在浏览器本地。

## 关于游戏

在汐溪谷经营一座农场，认识镇上的居民，经历昼夜、天气和四季变化，按照喜欢的节奏生活。

目前可以体验：

- 种植作物、饲养动物和加工农产品
- 钓鱼、采矿、觅食和制造
- NPC 日程、对话、委托与好感关系
- 恋爱、婚姻和农场生活
- 节日、收集包、成就与主线内容
- HD-2D 风格光照、景深、泛光和像素化渲染
- 键盘、鼠标及移动端触控操作

## 一起完善星屿物语

星屿物语已经可以完整游玩，但它不需要只有一种固定的样子。

这个项目的代码和美术资源都可以继续修改。玩法、剧情、角色、美术、音乐、界面、数值，乃至整个世界的设定和方向，都可以按照新的想法继续发展。可以只修正一个小问题，也可以进行一次完全不同的改造。

完成的修改欢迎通过 Pull Request 分享并合并回这个项目，大家可以一起讨论和完善。

也可以 Fork 到自己的仓库，继续制作和维护一个独立版本。它不必和原版保持一致，也不需要遵循这里现有的设计方向。

如果发布了自己的版本，欢迎通过 [Issue](https://github.com/ZTSCODE/starisle/issues) 把仓库或在线游玩链接发给我们。我们会尽量把这些社区版本整理并展示出来，让玩家看到更多不同的创意，也有更多可以选择和体验的星屿物语。

## 参与开发

普通玩家不需要执行下面的命令。想修改和测试项目时，可以先 Fork 本仓库，再克隆 Fork 后的版本：

```bash
git clone https://github.com/你的账号/starisle.git
cd starisle
npm install
npm run dev
```

根据终端提示打开本地开发地址。修改完成后，可以运行构建检查：

```bash
npm run build
```

构建结果会生成在 `dist/` 中。`dist` 是经过压缩和打包的发布文件，不是便于修改的源代码，因此不会提交到本仓库。

之后可以从自己的分支向本仓库提交 Pull Request，一起讨论并继续完善。

## 项目结构

```text
src/                    游戏源代码
  audio/                音乐、环境声和音效
  core/                 输入、时间、状态和存档
  data/                 物品、NPC、鱼类和配方数据
  render/               渲染、光照、天空和天气
  systems/              农耕、采矿、钓鱼和任务系统
  ui/                   游戏界面与程序化图标
  world/                场景和世界构建
public/.assetflow/       NPC 立绘、主界面图片和视频资源
docs/                    设计与技术文档
```

本仓库包含可直接修改的完整源代码与游戏运行所需的美术资源，不包含依赖目录、本地工具配置和构建产物。
