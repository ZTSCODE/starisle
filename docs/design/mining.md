# 设计文档：矿井与战斗系统

> 实现：src/systems/mining.js。对照组：《Stardew Valley》矿井（120层）。

## 0. 系统概述
80 层矿井（4 主题带×20 层）+ 程序生成楼层 + 实时战斗 + 挖掘/装备/电梯/宝箱/晕厥惩罚。接口：监听 `enter-mine`；发 `node-broken/monster-killed/mine-enter/mine-exit`；state `state.mine.elevator`、`state.player.equipment`。

## 1. 功能树
```
L1 矿井与战斗
├─ L2 楼层生成
│  ├─ L3 主题带 [视觉]
```

## 4. 边界与异常清单
- 2:00/体力透支在矿洞：先 exit 再昏倒（矿洞场景正确卸载，世界组恢复）
- 炸弹自伤致死：走同一晕厥流程，不重复扣钱（一次结算）
- 出梯后立刻回头：同一层重新生成（SDV 同款）
- 怪卡在墙里：怪物碰撞同玩家格，位移分轴判定
- 电梯直达未解锁层：面板只列出已解锁层
- 岩石蟹伪装/跳虫越墙：flyer 类允许越障碍，其余受格挡
- 背包满时开箱/掉落：物品原地弹跳提示，不消失
