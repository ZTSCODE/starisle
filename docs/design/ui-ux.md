# 设计文档：UI/UX 系统（HUD/菜单/对话/引导）

> 依据：AGENT_PROMPT §3.11 + docs/architecture.md（DOM/CSS 覆盖层）。对照组：《珊瑚岛》UI 手感 + 《Stardew Valley》菜单结构。

## 0. 系统概述
全部界面：HUD、TAB 大菜单（背包/技能/地图/图鉴/社交/设置/统计/任务/成就）、对话框、商店 UI、箱子 UI、制作/烹饪 UI、收集包 UI、节日 UI、标题界面（存档管理）、新手引导与提示条。接口：读取全部系统 state；发出 `ui-open/ui-close`（暂停时钟判定）、`ui-sound`。

| 项 | 值 | 理由 |
|---|---|---|
| 打字机速度 | 30 字/秒 | SDV 同款观感 |

| 教学条时长 | 8s 一次性 | 不打扰老玩家 |

## 4. 边界与异常清单
- 菜单打开时游戏暂停（时钟停、怪物停），商店/箱子/对话同样暂停；钓鱼小游戏与节日活动不暂停（实时玩法）。
- 背包满：获得物原地弹跳等待，不丢；商店购买数量受空格限制。
- 金钱不足：购买按钮灰+tooltip 提示差额。
- 删档防呆：需输入"确认"二字。
- 键位冲突：红提示且不允许保存直到解决。
- 对话中被攻击（矿井 NPC 不存在；过场在矿井不触发）——结构上不可能，过场仅安全区触发。
- 分辨率适配：UI 按 1920×1080 基准缩放，4:3~21:9 安全区居中。

## 5. 接口契约
- 监听：全部 state 变化（响应式刷新）、`ui-open/ui-close`
- 发出：`ui-sound`、`pause-request`
- state：`state.settings`（音量/画质/键位/UI缩放）、`state.ui.tutorialsSeen`
- 依赖：所有系统（只读聚合）

## 6. 完工三连问
1. 对照组还有什么行为我没有？——手柄支持（已给成立理由）；其余维度齐。
2. 六层反馈链核验：UI 交互=[操作]点击/拖放即时响应✅ [视觉]hover高亮/动画✅ [听觉]点击/翻页音✅ [UI]自身即UI层✅ [数值]金额/数量变化✅ [氛围]菜单开合景深✅。
3. 边界清单每条均有方案（§4）。
