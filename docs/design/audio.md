# 设计文档：音频系统（BGM/环境音/SFX）

> 依据：docs/research/visual-audio.md §5（终稿）。对照组：《Stardew Valley》原声与环境声结构。

## 0. 系统概述
全程序化 WebAudio 音频：NES 声部 step-sequencer BGM、分层环境声床、合成 SFX（3–4 变体）。接口：监听 `minute/weather-change/season-start/scene-change/ui/*` 等；暴露 `audio.sfx(name,opts)`、`audio.bgm(track)`、`audio.ambience(layers)`；三总线音量与设置页联动。

## 1. 功能树
```
L1 音频
├─ L2 引擎层
│  ├─ L3 三总线混音 [听觉]
│  │  └─ L4 music/ambience/sfx 三 GainNode → DynamicsCompressor → master；设置滑条 0–100 映射 gain²（感知线性）
│  ├─ L3 用户手势解锁 [操作]
│  │  └─ L4 首次点击/按键时 ctx.resume()；标题界面"开始"按钮即解锁点
│  └─ L3 变体与防重复 [听觉]
│     └─ L4 同名 SFX 注册 3–4 参数变体（playbackRate ±10%、滤波截止 ±15% 随机）；高频音 300ms 内不重复触发同一变体
├─ L2 BGM（≥8 首，循环无缝）
│  ├─ L3 四季主题曲×4 [听觉][氛围]
│  │  └─ L4 每首 32–64 小节 loop：春(明亮大调, 钢琴音色斑马+方波旋律, 100BPM)/夏(班卓琴感方波切分, 112BPM)/秋(小调民谣, 92BPM)/冬(冷合成垫+三角波, 80BPM)；白天户外播放，播完停 20–60s 再随机下一首（对标 SDV 静默交替）
│  ├─ L3 场景曲×4 [听觉]
│  │  └─ L4 标题(主题曲完整版)/矿井(阴暗小调+回声 delay, 层段越深配器越薄)/节日(欢快进行曲)/夜晚变奏(当日季节曲降速 0.8×+柔音垫)
│  ├─ L3 雨天规则 [听觉]
│  │  └─ L4 户外雨/暴雨：BGM 2s 淡出静音，仅留雨声层；室内 BGM 保留
│  └─ L3 无缝切换 [听觉]
│     └─ L4 换曲 = 旧曲 1.5s 淡出 + 新曲 1.5s 淡入；同曲循环点在小节边界（排程器对齐）
├─ L2 环境声床
│  ├─ L3 层管理 [听觉][氛围]
│  │  └─ L4 层注册表：鸟鸣(春晴白天)/蝉(夏晴 10–16时)/风(常驻, 大风增益+6dB)/雨(密/疏两档)/远雷(暴雨随机 20–60s)/夜虫(20:00–5:00)/海浪(海滩场景)/矿井水滴回响(矿洞)；每帧按 场景×时段×天气 计算目标增益，2s lerp
│  ├─ L3 合成源 [听觉]
│  │  └─ L4 风=粉噪+低通 400Hz 缓慢 LFO；雨=白噪+高通 1200Hz；蝉=5kHz 方波脉冲串 AM；鸟鸣=正弦滑音 chirp 随机排程(2–8s)；海浪=棕噪 0.1Hz LFO + 泡沫高通；矿井=水滴 sine 击发+大混响
│  └─ L3 脚步联动 [听觉]
│     └─ L4 走草丛时叠加沙沙声（短噪声 burst × 移动速度）
├─ L2 SFX 全套（对照 §5 清单逐一实现）
│  ├─ L3 脚步 [听觉] └─ L4 草(软噪声+低频)/土(中频 thump)/石(硬噪声+高频 click)/雪(挤压感带通噪声)；步频随移速，左右脚交替两变体
│  ├─ L3 农耕 [听觉] └─ L4 锄地(低通噪声爆发+thump，草地/土地变体不同)、播种(轻扑)、浇水(高通噪声扫频 300ms)、收获(上扬双音 arpeggio)、作物成熟提示(远处轻铃)
│  ├─ L3 采集 [听觉] └─ L4 砍树(木质 crack×3 渐强)、树倒(轰鸣+叶响)、敲石(石质 clank 变体按矿石类型)、拾取(方波双音)
│  ├─ L3 战斗 [听觉] └─ L4 挥剑(whoosh 带通扫频)/命中(钝击+怪叫)/受击(低频 punch+短失真)/怪叫(各怪特征：史莱姆 boing、蝙蝠尖啸…)/格挡(金属 clink)
│  ├─ L3 钓鱼 [听觉] └─ L4 抛竿(线轮嗖+入水扑通+涟漪)/咬钩(急促"哒哒哒"+感叹音)/收线(轮轴循环, 张力高时音调升)/脱钩(沮丧下行音)/上钩收获(胜利琶音)
│  ├─ L3 经济与 UI [听觉][UI] └─ L4 金币结算(硬币 cascade 按金额分段)、购买确认、UI 点击/翻页/开关菜单(纸感)、出售确认、错误(低 buzz)
│  ├─ L3 生活 [听觉] └─ L4 睡觉转场(柔下行琶音+画面渐暗同步)、升级(金光 fanfare)、节日欢呼(人群噪声+小号)、门(木轴吱呀)、动物叫声(鸡/牛/羊/猪/兔近景随机)
│  └─ L3 天气 [听觉] └─ L4 雷声三变体(近炸/中滚/远轰，按闪电强度)、雨起停过渡
└─ L2 与玩法联动
   ├─ L3 音乐情绪 [氛围] └─ L4 昏倒/晕厥时 BGM 低通滤波+降速 0.7，2s 恢复
   └─ L3 音量设置 [UI] └─ L4 主/音乐/音效三滑条实时生效并持久化 state.settings
```

## 3. 数值表
| 项 | 值 | 来源/理由 |
|---|---|---|
| 静默间隔 | 20–60s | SDV 轮换结构（wiki Soundtrack），本作取同类区间 |
| 变体抖动 | playbackRate ±10%、滤波 ±15% | Web Audio API 书 ch04（visual-audio.md 引） |
| 高频 SFX 去重 | 300ms | 工程惯例防 machine-gun 效应 |
| BGM BPM | 80–112 按季 | 季节情绪对标 SDV OST 配器描述 |

## 4. 边界与异常清单
- 浏览器自动播放限制：首次手势解锁，未解锁前所有调用静默入队丢弃，不报错。
- 标签页切后台：visibilitychange 时全总线淡出暂停，回来恢复。
- 大量 SFX 并发（战斗+雨+UI）：每类 SFX 同时发声数上限 4，超出丢弃最旧。
- 音量 0：滑条 0 时短路不排程，节能。
- 长时间运行：BGM 排程器只预排 2 小节，防 currentTime 漂移；噪声 buffer 复用不新建。
- 昏倒/过场打断：BGM 情绪滤波（功能树联动），不打断排程线程。

## 5. 接口契约
- 监听：`weather-change`、`season-start`、`scene-change`、`minute`、`player-action`(sfx 名)、`ui-sound`、`bgm-mood`
- 发出：无；暴露 `audio.sfx/bgm/ambience/setVolume`
- state：`state.settings.volumes {master,music,sfx}`
- 依赖：无（纯输出系统）

## 6. 完工三连问
1. 对照组还有什么行为我没有？——SDV 每季 3 首轮换，本作按 §5 底线每季 1 首+变奏（数量合规，轮换结构一致）；其余行为维度齐。
2. 六层反馈链：音频系统本身是六层中的"听觉层"提供者，所有 gameplay 动作的听觉层均经 `audio.sfx` 落地（见各系统设计文档逐项标注）。
3. 边界清单：自动播放/后台/并发/音量0/长跑/打断——全部有实现方案。
