## 1. 功能树（≥4层，叶子节点=可直接编码的具体行为）
```
L1 系统名
├─ L2 子功能A
│  ├─ L3 交互细节1 —— 六层标注：[操作][视觉][听觉][UI][数值][氛围]
│  │  ├─ L4 行为单元a（时序/参数/异常分支，可编码粒度）
│  │  └─ L4 行为单元b
│  └─ L3 交互细节2 …
└─ L2 子功能B …
```
叶子节点合格示例："抛竿分3段：举竿(100ms)→甩出(150ms)→浮漂入水(涟漪粒子+扑通声+镜头轻推)"。
