# 设计文档：农耕系统（耕地/播种/生长/收获/品质/肥料/洒水器/乌鸦/温室）

> 依据：RESEARCH.md §4.2 + docs/research/sdv-core.md §2。对照组：《Stardew Valley》农耕循环。

## 0. 系统概述
农场核心循环：锄地→播种→每日浇水→多阶段生长→收获→出货。含品质、肥料、洒水器、稻草人/乌鸦、巨型作物、温室。接口：读 `clock/weather/skills`；发 `crop-harvested`（技能XP/任务/统计）、`item-gained`；state `state.farm.tiles`、`state.farm.greenhouse`。

## 4. 边界与异常清单
- 满背包收获：果实原地弹跳等待，不消失（功能树）。
- 体力不足：动作起手前检查，不足时"太累了"气泡+拒绝动作（挥空也扣1点规则同SDV）。
- 雨天：全部耕地自动湿润，洒水器当日跳过；雨停后湿态保留到次日6:00。
- 节日当天作物照常生长（节日必晴）。
- 季末最后1天：24:00 枯萎结算在睡觉推进日期时执行；枯草木/镰刀清除。
- 乌鸦并发：乌鸦与稻草人范围逐株判定；多乌鸦选株去重。
- 温室与季节：温室内不受换季结算影响；温室作物不吃乌鸦。
- 2:00 昏倒在农田：正常走昏倒流程，作物不受影响。
- 爬藤格阻挡导致玩家被围：爬藤可用斧/镐拆除（掉1果实），留提示。

## 5. 接口契约
- 监听：`day-start`（生长/洒水器/乌鸦）、`season-start`（枯萎）、`tool-use`、`weather-change`
- 发出：`crop-harvested {cropId, quality, count}`、`item-gained`、`crop-withered`
- state：`state.farm.tiles[x][y] = {tilled, watered, fertilizer, crop:{id, stage, day, regrow}}`、`state.farm.sprinklers/scarecrows/greenhouse`
- 依赖：data/crops.js、data/items.js、skills（品质/XP）、weather
