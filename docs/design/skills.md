# 设计文档：技能与等级系统

> 依据：RESEARCH.md §4.3 + sdv-core.md §3。对照组：《Stardew Valley》技能系统。

## 0. 系统概述
5 技能（耕种/采矿/觅食/钓鱼/战斗）各 10 级：XP 获取、升级结算、配方解锁、5/10 级职业二选一。接口：监听各系统 XP 事件；发 `skill-levelup`；state `state.skills`.

## 1. 功能树
```
L1 技能
├─ L2 XP 获取
│  ├─ L3 来源映射 [数值]
│  │  └─ L4 耕种=收获作物(按作物值)+畜牧互动+5；采矿=敲石/矿(按矿种)；觅食=砍树14/树桩2/拾取7；钓鱼=钓获(按鱼难度)+蟹笼；战斗=击杀(按怪级)
│  └─ L3 飘字反馈 [UI][数值]
│     └─ L4 获得 XP 时对应技能图标色小字 "+N"（HUD 技能栏简显，菜单内可见进度条）
├─ L2 升级
│  ├─ L3 结算时机 [UI][听觉][氛围]
│  │  └─ L4 跨级在睡眠结算界面后依次弹出：金光 fanfare+全屏金边→技能图标升级动画→新配方列表滚动展示→次日满体力
│  ├─ L3 XP 表 [数值]
│  │  └─ L4 累计 100/380/770/1300/2150/3300/4800/6900/10000/15000（同 SDV）
│  └─ L3 工具熟练 [数值]
│     └─ L4 每级对应工具体力消耗 −0.1（10级时 2→1）
├─ L2 配方解锁
│  └─ L3 解锁表 [UI]
│     └─ L4 每级解锁配方集（见 §3 数值表，结构同 SDV 原创命名）；制作页新解锁配方闪烁"新"角标
└─ L2 职业
   ├─ L3 5级二选一 [UI][数值]
   │  └─ L4 升级结算时弹双卡选择(图标+效果描述，可留到次日再选——不做延迟，必须当场选，防呆)；选择写入 state 立即生效
   ├─ L3 10级分支 [UI][数值]
   │  └─ L4 由5级选择决定二选一分支（如耕作者→工匠+40%工匠品价 / 农业学家+10%生长）
   └─ L3 重置 [数值]
      └─ L4 小镇下水道雕像（社区中心修复后解锁）：捐 10,000g 重置某技能职业选择
```

## 3. 数值表（本作采用，结构同 SDV 原创命名）

| 觅食 | 护林人(木+25%) / 收集者(20%双倍) | 伐木工(树掉硬木)/榨取者(糖浆+25%) ；植物学家(必铱)/追踪者(显示位置) |
| 钓鱼 | 渔夫(鱼+25%) / 捕蟹人(蟹笼省料) | 垂钓者(+50%)/海盗(宝箱×2) ；水手(无垃圾)/诱饵大师(免饵) |
| 战斗 | 斗士(+10%伤,+15HP) / 侦查员(暴击×1.5) | 野蛮人(+15%)/防御者(+25HP) ；杂技演员(冷却半)/亡命徒(暴伤×2) |
升级配方解锁链：同 sdv-core §3.2–3.6 对应等级（本作配方集，详见 data/recipes.js 的 unlock 字段）。

## 4. 边界与异常清单
- 一天升多级：结算界面按级依次弹出，职业选择在对应等级弹窗完成。
- 5级未选职业到10级：不可能——5级弹窗强制当场选（防呆）。
- XP 溢出：升级后剩余 XP 保留累计。
- 职业重置后配方：已学配方保留，仅职业加成切换（对标 SDV）。
- 战斗 HP 加成回溯：选 +HP 职业时当前生命同步增加。

## 5. 接口契约
- 监听：`xp-gain {skill, amount}`
- 发出：`skill-levelup {skill, level}`（解锁配方通知 crafting/UI）
- state：`state.skills {farming:{xp,profession[]}, mining, foraging, fishing, combat}`
- 依赖：data/recipes.js、time-weather（睡眠结算）
