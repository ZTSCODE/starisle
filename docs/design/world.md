# 设计文档：世界与场景系统（地图结构/切换/碰撞）

> 依据：docs/architecture.md §5-6 + visual-audio.md 尺度约定。对照组：《Stardew Valley》地图分区结构（农场/镇/海滩/矿井）。

## 0. 系统概述
定义游戏全部场景的地理结构、场景切换、碰撞与寻路网格。接口：向 npc（日程点位）、foraging（刷新区域）、festivals（节日布置）、shops（建筑入口）提供命名点位与区域查询；监听 `scene-change` 请求并执行切换演出。

## 1. 功能树
```
L1 世界与场景
├─ L2 场景划分（5 室外 + N 室内）
│  ├─ L3 农场 farm（48×48 tile）[视觉]
│  │  ├─ L4 含：农舍(4×4 建筑+门点位)、农田区(约 24×20 可耕)、出货箱(1×1 交互)、邮箱(1×1)、池塘(水域, 可钓鱼)、鸡舍/畜棚地基(购建后生成)、温室地基(解锁后生成)、宠物窝
│  │  └─ L4 出口：南→镇、东→森林、北→山路(矿井)
│  ├─ L3 汐溪镇 town（56×48）[视觉]
│  │  ├─ L4 含：广场(节日主场地, 12×12 空地+装饰位)、杂货店/铁匠铺/动物店/酒吧/诊所/社区中心(大建筑)/民宅×6、路灯×10、公告板、河道穿镇(桥×2)
│  │  └─ L4 出口：北→农场、东→海滩、西→森林
│  ├─ L3 海滩 beach（40×32）
│  │  ├─ L4 含：沙滩(海钓区)、码头(旅行商人船停靠位)、礁石区(觅食)、潮汐池
│  │  └─ L4 出口：西→镇
│  ├─ L3 森林 forest（48×40）
│  │  ├─ L4 含：密林(砍树/觅食主区)、湖泊(湖钓区)、秘密林地(后期区域)、旅行商人车(周五/日)
│  │  └─ L4 出口：西→农场、东→镇
│  ├─ L3 山路 mountain（40×32）
│  │  ├─ L4 含：矿井入口(交互门)、矿车点(修复后快行)、采石场、山洞湖(矿洞湖钓区)
│  │  └─ L4 出口：南→农场
│  └─ L3 室内 interiors
│     ├─ L4 农舍室内(床/电视/厨房[升级后]/箱子)、各商店室内(柜台交互点+店主站位)、酒吧(老虎机=赌场)、社区中心室内(收集包祭坛)、鸡舍/畜棚室内(动物过夜)
│     └─ L4 室内统一 16×12 tile 规格，独立小场景，无昼夜光照（恒定暖光）
├─ L2 场景管理器
│  ├─ L3 切换演出 [视觉][听觉][氛围]
│  │  └─ L4 触发带(出口 2 tile 宽) → 画面 0.4s 渐黑 → 卸载旧场景 Group/挂载新场景 → 玩家落位到对应入口 → 0.4s 渐亮 + 场景名横幅淡入淡出(1.6s) + 环境声床切换
│  ├─ L3 按需加载 [性能]
│  │  └─ L4 仅当前场景挂载；NPC 在后台场景走逻辑日程（不渲染），进入场景时按当前时刻瞬移到日程点位
│  └─ L3 矿井特例
│     └─ L4 矿井为程序生成单层场景（见 mining 设计文档），进入/电梯/楼梯均走同一切换演出
├─ L2 碰撞与网格
│  ├─ L3 碰撞层 [操作]
│  │  └─ L4 每场景 Uint8 碰撞格：0=可走 1=阻挡 2=水域 3=可耕土 4=建筑门(交互)；玩家/NPC/动物圆形碰撞 vs 网格；爬藤作物格成熟后变阻挡
│  ├─ L3 寻路 [操作]
│  │  └─ L4 A* 网格寻路（NPC 日程移动 + 点击移动）；动态阻挡(放置物)增量更新
│  └─ L3 高度与视觉层次 [视觉]
│     └─ L4 地面高度 0.25m 步进(河岸/坡地)；角色 y = 地面高度；树冠层在角色经过时半透明(dither fade)
└─ L2 地图 UI 数据
   ├─ L3 世界地图 [UI]
   │  └─ L4 各场景俯视缩略图(离线渲染一次成图)+玩家实时位置+NPC 实时位置点(名字 tooltip)
   └─ L3 小地图不做——理由：俯视角视野已覆盖战术信息，世界地图承担导航（对照珊瑚岛亦无小地图）
```

## 3. 数值表
| 项 | 值 | 理由 |
|---|---|---|
| 农场尺寸 | 48×48 tile(=48×48m) | SDV 标准农场约 64×52，本作取紧凑值保证前期步行节奏 |
| 室内规格 | 16×12 | 统一规格降美术与碰撞成本 |
| 切换渐黑 | 0.4s×2 | 对标珊瑚岛切换时长观感 |
| 场景上限 | 室外5+室内~12 | 按需加载保证内存可控 |

## 4. 边界与异常清单
- 玩家在触发带内打开菜单：切换优先，菜单强制关闭。
- 节日当天广场封锁：前往广场入口显示节日提示并传送至节日活动（见 festivals）。
- NPC 跨场景移动与玩家同时过图：NPC 按日程时间轴结算，不与玩家切换产生竞争。
- 商店休息时间进门：门锁定 + 提示营业时间（联动 shops）。
- 睡觉/昏倒强制回农舍床：跨场景传送，走同一切换演出。
- 矿井内 2:00：昏倒结算后传送农舍（联动 mining/time）。

## 5. 接口契约
- 监听：`scene-change {target, spawn}`、`festival-setup {festivalId}`
- 发出：`scene-changed {sceneId}`（音频/光照/NPC 据此切换）
- state：`state.world.currentScene`、各场景动态阻挡、建筑拥有情况
- 依赖：data/maps（点位定义）、render/chunk（地形构建）
