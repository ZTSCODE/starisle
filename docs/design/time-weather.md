# 设计文档：时间/季节/天气系统

> 依据：RESEARCH.md §4.1 + sdv-core.md §1/§6。对照组：《Stardew Valley》时间系统。

## 0. 系统概述
驱动全局节律：游戏时钟（0.9s=1min）、日历（4季×28天）、每日运气、天气机（晴/多云/风/雨/暴雨/雪）。接口：发 `minute/hour/day-start/day-end/season-start/weather-change`；读 `state.settings.timeScale`；所有系统的节律源。

## 1. 功能树
```

│  └─ L3 天气预报 [UI]
│     └─ L4 电视天气预报频道播次日天气（图标+播报）；占卜频道播当日运气档(5档台词)
```

## 4. 边界与异常清单
- 菜单/对话/过场暂停时钟；钓鱼小游戏实时（对标 SDV 单人）。
- 昏倒时在矿井：按矿井规则额外结算（mining 联动），再回农舍。
- 节日当天 2:00 昏倒：节日活动 24:00 强制结束传送回家，避免与昏倒演出冲突。
- 暴雨闪电劈中洒水器/稻草人：不破坏设施，仅作物/树（对标 SDV）。
- 求雨图腾在冬季使用：变为下雪（冬季无雨）。
- 睡觉时不结算的事：无——所有日结算(生长/动物/设备/运气/天气)统一在 day-start 事件按序执行。
- 时间倍速与动画同步：动画按现实秒，时钟按倍速，互不干扰。

## 5. 接口契约
- 监听：`sleep-request`、`quality-change`、图腾使用
- 发出：`minute/hour/day-start/day-end/season-start/weather-change/luck-roll`
- state：`state.time {year, season, day, minute}`、`state.weather {today, tomorrow}`、`state.luck`
- 依赖：无（节律源）
